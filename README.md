# Facebook iOS App 📱

A Facebook-inspired social media application built for iOS using Swift and UIKit. This project focuses on creating a user-friendly social networking experience with a clean interface and essential social media features.

## 🚀 Features
- Modern social media user interface
- User profile screen
- News Feed UI
- Posts and interactive feed elements
- Friends and social networking UI
- Reusable UIKit components
- Responsive layouts using Auto Layout

## 🛠️ Technologies Used
- Swift
- UIKit
- Storyboard / XIB
- Auto Layout
- Xcode
